# Vibe ARF 0.1.2 maintenance release

This maintenance release keeps the Vibe ARF playbook version at `0.1.2` and
removes the retired standalone `ordo_visual_graph_generator` from the
distribution closure. The editor's native graph projection remains supported;
the former utility is retained only under the repository's labelled legacy
archive.

All EDIT, CLI_RUN, and MODEL_RUN profiles are rebuilt from this repository
source. The release tag is `vibe-arf-v0.1.2-maintenance.1`.
