# Vibe ARF 0.1.3 release

This release refreshes the three-profile Vibe ARF family from the current
repository language and embedded Ordo CLI. It includes current deterministic
replay, validation-layer, node-decomposition, documentation-graph, and
runtime-contract capabilities without introducing a second language authority.

The EDIT, CLI_RUN, and MODEL_RUN artifacts were built with the package-native
three-profile builder and jointly validated against their distribution contract.
The release tag is `vibe-arf-v0.1.3`.
