# SIMPLE_VERIFIED_DOCUMENT_CODE_IMPLEMENTATION v1.1

Reusable **simple** verified-document → code implementation pattern. It remains intentionally compact:

`INPUT → SAFE REPOSITORY FRESHNESS → ONE-SHOT PLAN/CLASSIFY → RISK GATE → IMPLEMENT+VERIFY → VERIFICATION GATE → COMPLETE`

The v1.1 upgrade adds safe pre-analysis Git freshness, repository-authority isolation, provisional implementation-family selection, deterministic eight-dimension change risk, verified-document target authority, and persisted-current verification truth.

The existing VIBE generic implementation-profile and repository-native documentation extensions are preserved. At most one profile/family may be selected; current repository evidence may correct it before mutation and always outranks packaged assumptions.

`HANDOFF_REQUIRED` and repository-refresh `BLOCKED` terminate without mutation. The advanced `VERIFIED_DOCUMENT_CODE_IMPLEMENTATION` pattern remains a separate explicit variant.
