# Playbook Regression Playbook

The Playbook Regression Playbook (PRP) is a versioned candidate playbook that orchestrates the Playbook Regression Harness (PRH) when a playbook is changed, migrated, or considered for release.

The current imported candidate is [`0.2.0-alpha.1`](versions/0.2.0-alpha.1/docs/QUICKSTART.md). PRP controls the regression journey; PRH performs the technical evaluation. The package is candidate-only until a full pilot and promotion review are complete.

PRP and PRH are authoring and release-validation aids. They do not change Ordo runtime behavior.
