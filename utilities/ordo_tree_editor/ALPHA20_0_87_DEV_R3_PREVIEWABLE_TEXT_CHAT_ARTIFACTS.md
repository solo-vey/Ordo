# alpha.20.0.87-dev — previewable text artifacts in chat

Chat artifact cards now open the side preview for supported textual artifacts, not only Markdown.

Previewable: Markdown, JSON, YAML, text/log, Python, CSV, XML, HTML, CSS, JavaScript/TypeScript, shell, TOML/INI/config, SQL.

- Markdown is rendered.
- JSON is pretty-printed when valid.
- Other text formats use a read-only source/code view.
- Download remains available from the same card.
- ZIP, PDF, binary, and unknown files remain download-only.

No runtime or playbook semantic changes.
