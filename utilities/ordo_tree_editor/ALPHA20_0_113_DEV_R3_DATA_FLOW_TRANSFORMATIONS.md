# alpha.20.0.113-dev — Data Flow transformation model

Data Flow now models producer/transformation mechanisms explicitly instead of drawing only direct variable relationships. Generic transformation categories include analyst interaction, AI transformation, deterministic derivation, Python/tool execution, template rendering, and packaging. The extractor also consumes package-level variable registries when they expose generic path/source_node traceability metadata, and resolves bare declared inputs plus proposal/draft/interpretation sources. No playbook source is modified.
