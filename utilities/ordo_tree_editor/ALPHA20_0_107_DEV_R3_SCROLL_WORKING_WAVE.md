# alpha.20.0.107-dev

- Scroll-to-latest control appears only when at least 100 px of transcript content remains below the viewport.
- While the model is working, the same control switches from the down arrow to three animated dots moving as a continuous wave.
- When model work finishes, the control returns to the down arrow if scrolling is still possible.
- Clicking the working indicator still scrolls to the latest message.
- Reduced-motion environments receive a static three-dot indicator.
