Start the local editor first

This page needs its local Python validation service. Do not open index.html directly.

  1. Open Terminal in the extracted ORDO_TREE_EDITOR folder.
  2. Run ./utilities/ordo_tree_editor/start_ordo_tree_editor.command.
  3. Use the http://127.0.0.1:8765 page that opens automatically.
