# alpha.20.0.88-dev — human-readable compilation failures

UI-only compilation/preparation failure hardening.

- Failed preparation modal is always dismissible via Close, Escape, or backdrop click.
- Compiler/validation JSON is summarized into human-readable sections.
- Affected node/gate IDs are surfaced when available.
- Raw compiler JSON is preserved under a collapsible Technical details section.
- The Editor remains usable after a failed playbook upload.
