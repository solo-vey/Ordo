# alpha.20.0.93-dev — Playbook Settings

Adds a read-only, registry-driven Playbook Settings workspace.

- Current values are read from the loaded Ordo source.
- Known alternatives and English meanings are read from the bundled language registry Markdown tables.
- No raw YAML block is required to understand the effective settings.
- The page is data-driven: future registry rows are discovered without front-end changes.
- Settings inspection does not mutate playbook semantics.
