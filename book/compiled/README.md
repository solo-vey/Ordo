# Archived compiled Ukrainian book editions

This directory is retained only on the `archive/books` branch.

The two Markdown files are historical, monolithic Ukrainian book builds. They
are not the active book source and must not be updated or used as the basis for
new documentation work. The maintained Ukrainian chapter source is
`book/uk/chapters/` on `main`.

The branch exists so that the historical editions remain retrievable without
duplicating them in the active repository tree.
