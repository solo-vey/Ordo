# Examples

This directory contains user-facing examples and maintainable example assets.

- [Vibe ARF release](https://github.com/solo-vey/Ordo/releases/tag/vibe-arf-v0.1.3) —
  the supported package for creating a first playbook in a model chat. The
  retired ARF Playbook Kit remains on the `archive/legacy` branch only.
- [`chat_first_playbook_starter/README.md`](chat_first_playbook_starter/README.md) — a
  small checked-in scenario example used to demonstrate the chat-first route.
- [`template_tooling/README.md`](template_tooling/README.md) — deterministic template
  inputs, registry, and validation examples.
