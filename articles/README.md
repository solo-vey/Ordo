# Published Articles

This directory is the repository record of articles published about Ordo and related AI-process work. It is intentionally maintained on the `Articles` branch, separate from the product branch.

Each platform has its own index. Every published article is stored in a dated directory with:

- `article.<language>.md` — the text published on the platform;
- `publication.yaml` — publication metadata, including the canonical platform URL, publication date, tags, and status.

## Platforms

| Platform | Index | Published articles |
| --- | --- | ---: |
| DEV Community | [DEV.to index](devto/README.md) | 5 |

## Editorial workflow

1. Write and approve the Ukrainian source text.
2. Prepare and approve the English adaptation for DEV.to.
3. Create a DEV.to draft; publication always requires separate approval.
4. After publication, archive the exact published Markdown and create or update `publication.yaml`.
5. Add the article to the relevant platform index.

The platform URL is the publication record. This branch is the durable project archive and editorial index.
