# Archived legacy packages

This directory contains package snapshots that are no longer part of the active
authoring route. The legacy ARF Playbook Kit is retained for compatibility,
migration, release provenance, and reproducibility only.

New playbooks should use the active [Vibe ARF package](../../packages/vibe_arf/).
Do not add new features to the archived ARF kit; shared Ordo runtime and
validation improvements belong in the active language/framework contours.
