# Regression contour included in the ARF Kit

This directory contains the expanded, English-language source needed to use
the candidate Playbook Regression Harness (PRH) and Playbook Regression
Playbook (PRP) while authoring or reviewing an ARF playbook.

- `prh/1.7.0/` is the standalone PRH source snapshot.
- `prp/0.2.0-alpha.1/` is the PRP orchestration playbook and its expanded PRH
  dependency snapshot.

The standalone PRH source in the repository remains the editable source of
truth. These copies make the ARF Kit self-contained; no ZIP binaries are
embedded in the repository or in the kit source.
