# Historical backlog and maturity state

This directory preserves the Markdown backlog, audits, inventories, and maturity
snapshots that were formerly stored in the active repository tree. They are
historical records, not the source of current work.

Current planning is tracked in GitHub Issues:
<https://github.com/solo-vey/Ordo/issues>.

The files remain unchanged except for this archival locator. In particular,
status values inside the historical backlog must not be interpreted as the
current status of an Issue.
