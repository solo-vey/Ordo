# Legacy utility archive

This directory contains companion utilities retired from the active Ordo
distribution. The contents are retained for provenance and historical
reproduction; they are not part of the current Vibe ARF or editor packages.

## Archived utilities

- `ordo_visual_graph_generator/` — the former standalone Mermaid/SVG/PNG
  renderer and annotation overlay utility. Editor-native graph rendering now
  owns the supported visual inspection path.
- `VISUAL_GRAPH_GENERATOR_INTEGRATION_PLAN.md` — historical integration plan.

Do not add new runtime dependencies on these paths. Historical references in
reports and book snapshots are intentionally preserved.
